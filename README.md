# FREONIX Website

Modern web application for FREONIX Pre-Order & Culinary Catalog built with React 19, Vite, and Tailwind CSS.

## Features

- **Product Catalog & Details**: Browse delicious menu items with nutritional information and dynamic pricing.
- **Admin Dashboard**: Comprehensive order, customer, product, category, and store status management with mock database storage.
- **Pre-Order System & Checkout**: Seamless checkout flow with WhatsApp integration.
- **Countdown Timer**: Real-time event & preorder deadline timer.
- **FAQ & Interactive Components**: Responsive UI with interactive product view and FAQs.

## Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite 8
- **Icons**: Lucide React
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM v7

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/vynookio-prog/Freotest.git
cd Freotest

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
